# This is the github repository for files associated with Vanessa Belanger's 2026 Master's Thesis 

# Repository Overview: 

This repository contains all code, datasets, and supporting materials associated with Vanessa Belanger’s 2026 Master’s thesis on automated misinformation detection.

# Methodological Note:

This project draws on previous literature and LLM instruction cards to inform the design of the experimental pipeline. 

Key design components—including prompt construction, train–test splits, parameter settings (e.g., temperature, token limits), and library selection—were guided by my own research on established methodological standards in the fake-news detection research.

While I have intermediate knowledge of the Python programming language, and developed an understanding of the scripts used throughout this project, all ML scripts were created with the assistance of an AI-based coding tool (Claude). More specifically, I used Claude to help debug coding errors that I could not resolve independently, and to provide suggestions and validation to ensure each script aligned with my stated research objectives and desired experimental design.

# Repository Folders: 

# Dataset claim extraction
This folder contains the scripts used to extract skeets from Failla and Rossetti’s (2024) and Gerard et al.’s (2023) datasets. Each script explores different NLP approaches, including claim extraction and keyword-based scraping methods. The sub-folder “Output files” contains the output files (skeets extracted) by the extraction scripts.

# Results
This folder contains the classification results from the study’s BERT and LLM models.

The LLM folder is organized by prompt condition (zero-shot and few-shot), where each sampled model has its own folder of results. The overall folder within the LLM directory contains the item-level prediction master dataset, which was used to model the study’s GLMMs.

Similarly, the BERT folder contains a subfolder with item-level predictions generated by each model. The fine_tune_baseline folder contains the script used to generate visual plots from BERT-based results. The cross-content evaluation folder contains scripts for a test that was not included in this thesis and can therefore be disregarded.

# Source datasets
This folder contains a comparatively small sample of Failla and Rossetti’s (2024) dataset, which consists of approximately 235 million skeets. This sample was used to perform claim extraction and develop the dataset used in this study.

# Task Code
This folder contains the scripts used for experimentation. It includes the two sub-datasets (UGC/NGC_Master_Ex.csv), which were stored in this folder for ease of retrieval within scripts, as well as the BERT train–test scripts and the LLM zero-shot and few-shot scripts. 

It also includes scripts used to generate some of the descriptive visuals for this thesis (though I later transitioned to using R for visualization).
